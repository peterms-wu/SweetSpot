# 模型比較紀錄

> **2026-10-18 改寫（feature 014 FR-008）**：這份紀錄會隨 repo 公開。逐款表與文中的遊戲名稱換成代號（「遊戲 01」……，同一款在各段用同一代號），數字、判定與結論都沒有改；代號與遊戲的對照只留在作者私人的紀錄裡。這是改寫，不是新的比較，不算任何比較的次數（憲章 IV）。

這份文件**只附加、不修改**（spec FR-030）。每一筆由 `steamsage compare … --record` 產生，或在建立第一個模型時手動附加。

- **判定規則**（FR-029）：候選模型「優於」現行模型的條件是：
  - 台灣區（≤12 個月）的 Brier 差距（候選 − 現行）95% 區間上限 < 0，**而且**
  - 美國區（1–5 年）的區間下限 ≤ 0，也就是沒有顯著變差。

  區間是依遊戲成對重抽樣 2,000 次得到的。
- **比較條件**（FR-028）：兩份結果在同一區域的資料集識別碼必須相同。
  只有一份跑美國區時，兩個模型的差異必須只在「只影響台灣區」的參數，美國區視為差距 0。
- **現行模型**（FR-031）：只有判定「優於」才能更換。第一個模型的判定是「建立下限」，
  參數取網格中台灣區 Brier 最低的設定，不要求顯著優於其他設定。
- Brier 分數越低越好。每款遊戲同權重：先算每款遊戲的平均，再平均所有遊戲。
